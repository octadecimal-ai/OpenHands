# OpenHands Process Index

Ten katalog zawiera operacyjne dokumenty pracy OpenHands nad doprecyzowaniem systemu multiagentów Octadecimal.

## Od czego zacząć

Każdy nowy wątek powinien przeczytać w tej kolejności:

1. `docs/openhands/working-rules.md` - obowiązujące zasady pracy.
2. `docs/openhands/conversation-log.md` - przebieg pytań, odpowiedzi i ustaleń.
3. `docs/openhands/decision-register.md` - skrócony rejestr decyzji.
4. Dokumenty źródłowe potrzebne do bieżącego epizodu, zwykle `README.md`, `CONTRIBUTING-to-analize-and-improve.md` i wybrane pliki z `docs/`.

## Pliki

- `working-rules.md` - zasady procesu, zmieniane ręcznie przez użytkownika albo przez agenta wyłącznie na wyraźne polecenie.
- `conversation-log.md` - pełniejszy dziennik rozmów projektowych.
- `decision-register.md` - decyzje z rationale, konsekwencjami i powiązanymi pytaniami.
- `questions-prompts/` - prompty przygotowane dla ręcznego researchu prowadzonego przez użytkownika w różnych modelach LLM.
- `research-files/` - wyniki researchu dostarczane przez użytkownika do późniejszej analizy.
- `sessions/` - rejestracje sesji agentów.
- `tasks/` - raporty statusu zadań z Reminders.

## Zasada praktyczna

Jeżeli wątek zaczyna nowy temat, najpierw odtwarza kontekst z tych plików, potem proponuje jeden mały następny krok. Jeżeli wątek podejmuje decyzję lub uzgadnia zasadę, zapisuje ją w logu oraz w rejestrze decyzji.
