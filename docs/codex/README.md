# Codex Process Index

Ten katalog zawiera operacyjne dokumenty pracy Codex nad doprecyzowaniem systemu multiagentów Octadecimal.

## Od czego zacząć

Każdy nowy wątek powinien przeczytać w tej kolejności:

1. `docs/codex/working-rules.md` - obowiązujące zasady pracy.
2. `docs/codex/conversation-log.md` - przebieg pytań, odpowiedzi i ustaleń.
3. `docs/codex/decision-register.md` - skrócony rejestr decyzji.
4. Dokumenty źródłowe potrzebne do bieżącego epizodu, zwykle `README.md`, `CONTRIBUTING-to-analize-and-improve.md` i wybrane pliki z `docs/`.

## Pliki

- `working-rules.md` - zasady procesu, zmieniane ręcznie przez użytkownika albo przez Codex wyłącznie na wyraźne polecenie.
- `conversation-log.md` - pełniejszy dziennik rozmów projektowych.
- `decision-register.md` - decyzje z rationale, konsekwencjami i powiązanymi pytaniami.

## Zasada praktyczna

Jeżeli wątek zaczyna nowy temat, najpierw odtwarza kontekst z tych plików, potem proponuje jeden mały następny krok. Jeżeli wątek podejmuje decyzję lub uzgadnia zasadę, zapisuje ją w logu oraz w rejestrze decyzji.
